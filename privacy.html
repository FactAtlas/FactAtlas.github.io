Privacy Policy

Last updated: November 25, 2026

This policy describes how Fact Atlas Uploader (the "App") and this website handle information. The App is a private tool operated by the owner of the Fact Atlas YouTube channel and is used exclusively to manage that channel.

1. Data the App accesses

With the channel owner's explicit consent via Google OAuth, the App uses the YouTube Data API to:

  • upload videos and their titles, descriptions and tags to the Fact Atlas channel,
  • update the channel banner image of the Fact Atlas channel,
  • read public statistics (views, likes, comments, privacy status) of videos uploaded by the App.

The App does not access, collect or store data of any other YouTube or Google user.

2. How data is stored

The OAuth access token and a list of uploaded video IDs and their statistics are stored only locally on the channel owner's computer. No data is sent to any server other than Google's APIs. No data is sold, shared with third parties or used for advertising.

3. Google API Services User Data Policy

Fact Atlas Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The App uses YouTube API Services; by using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy.

4. Revoking access

Access granted to the App can be revoked at any time on the Google Account permissions page. Locally stored tokens are then useless and can be deleted.

5. This website

This website is a static page hosted on GitHub Pages. It uses no cookies, no analytics and no tracking. GitHub may log technical data such as IP addresses for security purposes; see the GitHub Privacy Statement.
